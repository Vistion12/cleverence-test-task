# Cleverence Test Task

Тестовое задание для компании «Клеверенс». Решение состоит из трёх задач.

## Структура решения

| Проект | Задача | Описание |
|---|---|---|
| src/Compression | Задача 1 | Алгоритм компрессии и декомпрессии строки |
| src/CountServer | Задача 2 | Потокобезопасный счётчик на ReaderWriterLockSlim |
| src/LogProcessor | Задача 3 | Консольная программа стандартизации лог-файлов |
| tests/* | — | Юнит-тесты для всех задач |

## Требования

- .NET 8 SDK
- Visual Studio 2022

## Сборка

dotnet build

## Запуск тестов

dotnet test

## Задача 1 — Компрессия строки

Алгоритм сжатия строки: группы одинаковых символов заменяются на sc, где s — символ, c — количество.

Пример:

Вход:  aaabbcccdde
Выход: a3b2c3d2e

Классы:

- IStringCompressor / StringCompressor — сжатие
- IStringDecompressor / StringDecompressor — распаковка

## Задача 2 — Потокобезопасный счётчик

Статический класс с методами GetCount() и AddToCount(int value).

Поведение:

- Читатели работают параллельно
- Писатели — эксклюзивно
- Читатели ждут завершения записи

Реализация:

- ReaderWriterLockSlim для синхронизации

## Задача 3 — Стандартизация лог-файлов

Консольная программа для приведения логов к единому формату.

### Входные форматы

Формат 1:

10.03.2025 15:14:49.523 INFORMATION Версия программы: '3.4.0.48729'

Формат 2:

2025-03-10 15:14:51.5882| INFO|11|MobileComputer.GetDeviceId| Код устройства: '@MINDEO-M40-D-410244015546'

### Выходной формат

Поля разделены табуляцией:

Дата Время Уровень ВызвавшийМетод Сообщение

Дата приводится к dd-MM-yyyy.
Уровень логирования: INFORMATION -> INFO, WARNING -> WARN.
Если метод отсутствует — значение DEFAULT.

### Запуск

LogProcessor.exe input.log output.log problems.txt

- input.log — входной файл с логами
- output.log — стандартизированные записи
- problems.txt — невалидные строки в исходном виде

### Пример

input.log:

10.03.2025 15:14:49.523 INFORMATION Версия программы: '3.4.0.48729'
2025-03-10 15:14:51.5882| INFO|11|MobileComputer.GetDeviceId| Код устройства: '@MINDEO-M40-D-410244015546'
невалидная строка

output.log:

10-03-2025    15:14:49.523    INFO    DEFAULT    Версия программы: '3.4.0.48729'
10-03-2025    15:14:51.5882   INFO    MobileComputer.GetDeviceId    Код устройства: '@MINDEO-M40-D-410244015546'

problems.txt:

невалидная строка
